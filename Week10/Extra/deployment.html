Week 10 · Exercise 3

Deploy the Book Search App

Prepare your app and publish it with GitHub Pages.

Open the working Book Search App

  1. Get your Book Search App from Weeks 6–7

    Open your previous lab folder. Make sure it has an index.html with working search functionality.

  2. Run through the deployment checklist (Topic 8)

    Fix any absolute paths. Remove debug console.log calls. Make sure the app works locally.

  3. Create a new GitHub repository

    Name it webpro-book-search. Make it public and do not initialize it with a README.

  4. Push your Book Search App files to the new repository

    Initialize Git, stage your files, commit with the message Deploy Book Search App, connect the remote repository, and push to main.

  5. Enable GitHub Pages

    In the repository, open Settings → Pages, select main and the root folder, then save. Wait for the site to deploy and test the live URL.

  6. Submit the live URL

    Submit the tested URL on the LMS. Example: https://jdoe.github.io/webpro-book-search/
