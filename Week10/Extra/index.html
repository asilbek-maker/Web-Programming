Deploy Your Book Search App to GitHub Pages

  1. 1

    Get your Book Search App from Weeks 6–7

    Open the folder from your previous lab. Make sure it has an index.html with working search functionality. You can open the Week 7 Book Finder.

  2. 2

    Run through the deployment checklist (Topic 8)

    Fix any absolute paths. Remove debug console.log calls. Make sure it works locally.

  3. 3

    Create a new GitHub repo

    Name it webpro-book-search. Make it Public. Do NOT initialize with README.

  4. 4

    Push your Book Search App files to the new repo

    git init, git add ., git commit -m "Deploy Book Search App", connect remote, git push.

  5. 5

    Enable GitHub Pages

    In the repo (Settings → Pages → main → root → Save). Wait for the site to deploy. Test the live URL.

  6. 6

    Submit the live URL

    Submit it on LMS. Your deployed app: https://asilbek-maker.github.io/webpro-book-search/ — test it in an incognito window first!
