Homework 1 · Personal portfolio

Personal Portfolio Repository & Commit History

Created a personal portfolio repository on GitHub called portfolio and published it with GitHub Pages. Its index.html includes my name, photo, bio, skills and links to three course projects, designed as a BECK “drawing set” where solid lines mean built and dashed lines mean planned. It uses semantic landmark HTML, a responsive layout with a mobile hamburger drawer, and JavaScript interactions: an interactive terminal, Lenis smooth scrolling, project case-study dialogs and a paper / blueprint theme toggle, all respecting reduced-motion settings. Built up over 18 meaningful commits with clear messages.

Git & version control

How the portfolio was built and shipped

  1. Create the repository. New public repo on GitHub named portfolio, cloned to my computer.
  2. Work in small steps. Each change — structure, styling, hero, mobile drawer, smooth scroll, screenshots, redesign — is its own commit.
  3. Write clear messages. Short, imperative messages that say what changed, e.g. “Add project stacks and source links”.
  4. Push to main. Every commit is pushed so the history is visible on GitHub.
  5. Deploy with GitHub Pages. Pages serves the main branch at asilbek-maker.github.io/portfolio/.

terminal

# 1. get the repo
git clone https://github.com/asilbek-maker/portfolio.git
cd portfolio

# 2. one change = one commit
git add index.html
git commit -m "Create portfolio page structure"

git add styles.css
git commit -m "Style the BECK portfolio"

# 3. publish
git push origin main

# 4. check the history
git log --oneline
