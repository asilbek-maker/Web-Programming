Portfolio Gallery Component

A React project called portfolio-gallery, set up with the Create React App structure. A ProjectCard component shows one project’s title, description, tech stack, GitHub link and demo link. ProjectList renders an array of six real projects as cards, and a FilterBar filters them by technology. The filter buttons are built from the project data, so a new technology gets its own button automatically. The app is deployed to GitHub Pages by a GitHub Actions workflow on every push to main.

How the filter works

State lives in App, components just receive props

  1. Data first. Each project in src/data/projects.js has a tech array, e.g. ["Python", "Flask"].
  2. Build the buttons. App counts every technology across all projects and passes the list to FilterBar.
  3. Lift state up. useState("All") in App holds the active filter; FilterBar calls onChange when a button is clicked.
  4. Filter, then render. App keeps only the projects whose tech includes the active one and hands them to ProjectList.
  5. Deploy. A GitHub Actions workflow runs npm run build and publishes the build to GitHub Pages.

src/App.js

// the chosen technology
const [active, setActive] = useState("All");

// keep only matching projects
const visible = active === "All"
  ? projects
  : projects.filter((p) => p.tech.includes(active));

return (
  <>
    <FilterBar
      technologies={technologies}
      active={active}
      onChange={setActive} />
    <ProjectList projects={visible} />
  </>
);
