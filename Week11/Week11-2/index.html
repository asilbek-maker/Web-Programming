Task 11-A · React components & props · 30 pts

Student Profile Cards

A Vite + React project called task11. The StudentProfileCard component takes five props (name, studentId, major, year and gpa) and renders them as a formatted card. App.jsx is a Student Directory that uses the component three times: my card and two classmates'. The parent passes the data down as props, and the card only reads it. The cards are styled with hand-written CSS, with no framework.

How props work here

The parent passes data down, the card only reads it

  1. Passed like attributes. App writes <StudentProfileCard name="…" year={3} />. Strings go in quotes, numbers in { }.
  2. Received as one object. React calls the function with props, and the card destructures it to { name, studentId, major, year, gpa }.
  3. Read-only. The card never changes its props. It only puts them into JSX with { }.
  4. Reusable. One component, three cards: the same function runs with different data each time.
  5. Deploy. npm run build writes the site to Week11-2/app/, and GitHub Pages serves it from main.

src/StudentProfileCard.jsx

// 5 props, destructured
function StudentProfileCard({
  name, studentId, major, year, gpa
}) {
  return (
    <div className="profile-card">
      <div className="card-header">
        <h2>{name}</h2>
        <span>ID: {studentId}</span>
      </div>
      <div className="card-body">
        <p>Major: {major}</p>
        <p>Year: {year}</p>
        <p>GPA: {gpa}</p>
      </div>
    </div>
  );
}
