Code challenge

ProductCard with both bonuses

  1. Four props. name, price, rating and inStock, destructured in the parameter list.
  2. Bonus 1. The rating is shown as stars plus the text “4.5 / 5 stars”.
  3. Bonus 2. When inStock is false, the card is greyed out and a ternary swaps “In stock” for “Out of Stock”.
  4. Reused. The same component renders three products with different props.

src/exercises/ProductCard.jsx

function ProductCard({ name, price, rating, inStock }) {
  return (
    <div className="card" style={inStock
      ? undefined
      : { opacity: 0.55, filter: 'grayscale(1)' }}>
      <h3>{name}</h3>
      <p>₩{price.toLocaleString('ko-KR')}</p>
      <p><Stars rating={rating} />{rating} / 5 stars</p>
      {inStock
        ? <p>In stock</p>
        : <p><strong>Out of Stock</strong></p>}
    </div>
  );
}
