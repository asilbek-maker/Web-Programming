Interactive Shopping Cart

A Vite + React app called shopping-cart. The ShoppingCart component holds one piece of state: an array of cart items. It renders a product list of six items, each with a name, price and image, next to a cart sidebar. Add, Remove and the +/− quantity buttons all replace the array with a new one, never mutating it. The item count and total price are computed from that array on every render.

How the cart state works

One array in state, a new copy on every change

  1. One owner. ShoppingCart is the nearest common parent of the product list and the cart panel, so the cart state lives there.
  2. Add. If the product is new, spread it into a new array with quantity: 1. If it is already there, map it to a copy with quantity + 1.
  3. Remove. filter returns a new array without that item.
  4. + / −. map replaces only the changed item. Going below 1 filters the line out of the cart.
  5. Derive, don’t store. The count and total are calculated with reduce on each render, so they can never go out of sync.

src/components/ShoppingCart.jsx

const [cart, setCart] = useState([]);

// add: new array, or bump quantity
setCart(prev => prev.find(i => i.id === p.id)
  ? prev.map(i => i.id === p.id
      ? { ...i, quantity: i.quantity + 1 } : i)
  : [...prev, { ...p, quantity: 1 }]);

// remove: filter makes a new array
setCart(prev => prev.filter(i => i.id !== id));

// CartPanel: computed, not stored
const total = cart.reduce(
  (sum, i) => sum + i.price * i.quantity, 0);
