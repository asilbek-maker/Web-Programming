Counter with History

A Vite + React app called counter-history. CounterWithHistory uses two state variables: count and a history array. +1, −1 and Reset each set the new count and add it to history, keeping only the last five values. Undo moves the count back to the previous value and drops the last history entry. Undo is disabled when there is nothing to undo.

How it works

Two state variables that change together

  1. Start. count is 0 and history is [0].
  2. Change. +1, −1 and Reset all call change(next), which sets the count and appends it to history.
  3. Keep five. [...prev, next].slice(-5) builds a new array holding only the last five values. There is no push.
  4. Undo. Set the count to history[history.length - 2], then slice(0, -1) drops the last entry.
  5. Guard. With a single history entry there is nothing to undo, so the button is disabled.

src/CounterWithHistory.jsx

const [count, setCount] = useState(0);
const [history, setHistory] = useState([0]);

function change(next) {
  setCount(next);
  setHistory(prev =>
    [...prev, next].slice(-5));
}

function undo() {
  if (history.length < 2) return;
  setCount(history[history.length - 2]);
  setHistory(prev => prev.slice(0, -1));
}
