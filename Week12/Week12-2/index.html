How the weather effect works

Search changes → effect runs → old request cancelled

  1. One dependency. search is replaced with a new object on every submit, or by Use my location.
  2. Resolve the place. A city name goes through the Open-Meteo geocoding API first. Coordinates are checked in the form.
  3. Fetch the weather for that latitude and longitude, then store the place and the data together.
  4. Errors. An unknown city, HTTP 429 and network failures each get their own message.
  5. Cleanup. controller.abort() cancels the old request, so stale results never show.

weather-dashboard/src/components/WeatherDashboard.jsx

useEffect(() => {
  const controller = new AbortController();

  async function load() {
    setStatus('loading');
    try {
      const where = search.kind === 'city'
        ? await findCity(search.name, controller.signal)
        : { ...search };
      const data = await getWeather(
        where.latitude, where.longitude, controller.signal);
      setPlace(where);
      setWeather(data);
      setStatus('ready');
    } catch (err) {
      if (err.name === 'AbortError') return;
      setError(err);
      setStatus('error');
    }
  }

  load();
  return () => controller.abort(); // cleanup
}, [search]);
