Book Finder

Search the Open Library catalog and explore books in a clean card layout.

Six steps → one complete app

  1. Task 1 — HTML Structure

    Set up a semantic header, search form, status, and results section.

  2. Task 2 — CSS Layout & Cards

    Use CSS variables, a flexbox search bar, and a responsive card grid.

  3. Task 3 — JS DOM: Wire the Form

    Listen for submit, prevent page reload, and read the search input.

  4. Task 4 — Fetch: Call the API

    Fetch books from Open Library, check the response, and parse JSON.

  5. Task 5 — Challenge: Display Cards

    Create book cards with DOM elements and add them to the results.

  6. Task 6 — Extra: Loading & Errors

    Show skeletons, disable the button, and handle empty or failed searches.
