CSS Validation States

Enter an invalid email to see the red border, then correct it to see the valid state. Focus a control to see its outline.

The fields change style as their values change.

CSS pseudo-classes

input:valid { border-color: green; }
input:invalid:not(:placeholder-shown) {
  border-color: red;
}
input:focus { outline: 3px solid teal; }
