JavaScript Form Validation

Use browser validation for required fields and JavaScript to make sure both passwords match.

Create an account

Complete every field to try the validation.

What to try

  1. Submit the empty form to see the browser's required-field checks.
  2. Enter an invalid email or a password shorter than eight characters.
  3. Enter different passwords, then correct them and submit again.

Built-in constraints check required fields, email format, and password length. JavaScript uses the Constraint Validation API to check that the passwords match.
