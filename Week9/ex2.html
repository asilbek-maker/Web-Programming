Add a Skip Link

A skip link lets keyboard users bypass repeated navigation and jump to the page content.

Try it with your keyboard

  1. Reload this page.
  2. Press Tab. The “Skip to main content” link should receive focus.
  3. Press Enter. Focus should move to the main content.

Add these parts to your project

<a class="skip-link" href="#main-content">Skip to main content</a>
<main id="main-content" tabindex="-1">...</main>

Use CSS to move the link off-screen until it receives keyboard focus. Keep a visible focus outline.
