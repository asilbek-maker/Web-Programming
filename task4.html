Frequently Asked Questions

What is semantic HTML?

Semantic HTML means choosing tags based on their structural meaning (like <header>, <article>, or <nav>) rather than how they visually look.

What is the difference between class and ID in HTML?

An id must be unique to a single element on a page, whereas a class can be reused across multiple elements to apply shared styles or behavior.

Why should I use the <main> element?

The <main> element represents the dominant, unique content of the body. It helps screen readers skip repetitive navigation links and jump straight to the page's core content.

What is CSS Grid used for?

CSS Grid is a two-dimensional layout system used to arrange elements in columns and rows, making it ideal for overall page layouts and complex UI components.
